# Contributing to MonarchAegis

Thanks for your interest in contributing! Please read this before opening a pull
request — the CLA requirement in particular.

## License and the Contributor License Agreement (CLA)

MonarchAegis is licensed under **AGPL-3.0-or-later**, and is **also** offered
under a separate commercial license. To keep that dual-licensing possible, the
project must hold the rights to relicense everything it ships.

Therefore **every contribution requires agreeing to the Contributor License
Agreement (CLA)** in [CLA.md](CLA.md) before it can be merged.

- You **retain copyright** in your contribution.
- You grant the maintainer a broad, irrevocable license to use, sublicense, and
  **relicense** your contribution — including under commercial terms.

This is what prevents a single un-CLA'd contribution from making the commercial
edition legally impossible. It is a hard requirement — PRs cannot be merged
without it. Signatures are collected automatically on pull requests via a CLA
bot (e.g. [CLA Assistant](https://cla-assistant.io/)); you'll be prompted the
first time you open a PR.

## Before you open a PR

- **Discuss substantial changes first** by opening an issue — it saves everyone
  time if the direction isn't a fit.
- **Keep PRs focused** — one logical change per PR.
- **Include tests** for behavior changes. Run the suite first:
  ```bash
  ./run_tests.sh
  ```
- **Match the surrounding style** — comment density, naming, and idioms.

## Security

Please do **not** open public issues for security vulnerabilities. Report them
privately to the maintainer instead.
